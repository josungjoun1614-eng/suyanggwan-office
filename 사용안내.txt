수양관 사무 자동화 웹사이트 — 사용 안내
==========================================

■ 들어 있는 파일
  index.html  : 웹사이트 첫 화면
  app.js      : 기능 (작업 일지, 사진첩, 지출결의서, 식수표, 할 일, 시설 점검, 재고, 연락처, 설정)
  style.css   : 화면 모양 (인쇄용 A4 양식 포함)
  config.js   : 저장소(Supabase) 연결 정보 — 지우거나 고치지 마세요

  네 파일은 항상 같은 폴더에 함께 두어야 합니다.

■ 바로 써 보기 (내 컴퓨터)
  압축을 풀고 index.html 을 더블클릭하면 브라우저(크롬 권장)에서 열립니다.
  인터넷만 연결돼 있으면 데이터가 저장되고, 다른 컴퓨터·휴대폰과 같은 내용이 보입니다.

■ 인터넷 주소로 올리기 (직원들이 휴대폰으로 쓰려면)
  가장 쉬운 방법: Netlify Drop
    1) https://app.netlify.com/drop 에 접속
    2) 압축 푼 폴더를 통째로 화면에 끌어다 놓기
    3) 생기는 주소(예: https://○○○.netlify.app)를 직원들에게 공유
    ※ 주소를 계속 쓰려면 Netlify 무료 계정으로 로그인해 두세요.
  또는 GitHub Pages, 학교/회사 웹 서버 등 어디에 올려도 됩니다 (파일만 올리면 동작).

  휴대폰에서는 브라우저 메뉴의 "홈 화면에 추가"를 누르면 앱처럼 쓸 수 있습니다.

■ 처음 할 일
  설정 메뉴에서
   - 직원 명단 확인 (조성준, 최용길, 이점용, 이흥달 넣어 둠)
   - 결재자 지정 (담당 = 최용길 지정해 둠. 팀장·총무부장·사무처장은 비어 있음)
   - 식수 인원·단가·식당 (조성준, 서만봉 / 10,000원 / 금남꽃게 — 실제 단가로 고치세요)
   - 시설 점검 항목 (기본 10개 넣어 둠)

■ 주요 기능
  - 작업 일지: 1~7번 항목 작성, 사진 업로드(작업 전/중/후), 결재 도장, A4 인쇄
  - 사진첩: 날짜별·작업 전/중/후로 사진 모아 보기, 크게 보기
  - 지출결의서: 내역 입력하면 합계·한글 금액(금 ○○원정) 자동, 영수증 사진, 결재, 인쇄
  - 식수표: 칸을 눌러 0→1→2식, "평일 모두 채우기", 버튼 하나로 식대 지출결의서 자동 작성
  - 할 일: 마감일·담당자, 상태 버튼으로 할 일→진행중→완료
  - 시설 점검: 항목별 양호/불량/조치완료, 불량 건수 집계, 인쇄
  - 재고: 입고/출고 누르면 현재고 자동 계산, 최소 보유량 이하면 빨간색 표시
  - 연락처: 업체·거래처 검색, 휴대폰에서 번호 누르면 바로 전화
  - 홈: 이번 달 일지·결재 대기·지출·식수·남은 할 일·재고 부족을 한눈에

■ 수양관 6곳
  삼봉리수양관 · 안산수양관 · 몽산포수양관 · 덕정수양관 · 충주수양관 · 청풍기도원
  - 한 사이트를 6곳이 함께 쓰고, 각 수양관은 자기 자료만 보고 씁니다.
  - 팀원 계정마다 소속 수양관이 정해져 있습니다. 로그인하면 그 수양관 자료만 보입니다.
  - 본부 계정(소속 없음)은 6곳을 모두 볼 수 있고, 오른쪽 위 선택칸에서 수양관을 바꿉니다.
  - 기관 이름, 직원 명단, 결재자, 식수 인원·단가, 점검 항목은 수양관마다 따로 정합니다.
  - 수양관 관리자는 자기 수양관 팀원 계정만, 본부 관리자는 모든 계정을 관리합니다.

■ 로그인 · 팀원 계정
  - 팀원마다 아이디와 비밀번호로 로그인합니다. 로그인하지 않으면 아무 내용도 볼 수 없습니다.
  - 첫 관리자 계정: 아이디 admin (조성준). 처음 로그인한 뒤 오른쪽 위 "비밀번호 변경"으로 꼭 바꾸세요.
  - 팀원 추가: 관리자가 설정 → 팀원 계정 → "+ 팀원 계정 만들기"에서 이름·아이디·처음 비밀번호를 정해 알려 줍니다.
  - 비밀번호를 잊으면: 관리자가 설정 → 팀원 계정 → 관리 → "비밀번호 새로 정하기".
  - 그만둔 사람: 관리 → "사용 중지". 로그인은 막히고, 남긴 기록은 그대로 남습니다.
  - 권한: 관리자 = 설정 변경·계정 관리 가능 / 직원 = 일지·결의서 등 작성만 가능.

■ 수정·삭제는 결재자 승인 후 반영
  - 이미 저장한 작업 일지·지출결의서·시설 점검은 바로 고치거나 지울 수 없습니다.
  - "수정 요청" / "삭제 요청"을 누르고 사유를 적으면 "승인 요청" 메뉴에 올라갑니다.
  - 그 수양관의 결재자(설정의 결재자 지정에 있는 사람)나 관리자가 승인하면 반영되고, 반려하면 그대로 남습니다.
  - 승인 전에는 자료 화면 위에 "승인 대기 중인 요청"이 표시됩니다. 요청한 사람은 대기 중에 요청을 취소할 수 있습니다.
  - 새로 쓰는 것, 식수표·할 일·재고·연락처는 승인 없이 바로 저장됩니다.

■ 결재
  - 결재는 로그인한 본인 이름으로만 찍힙니다.
  - 설정에서 결재자를 지정한 칸은 그 사람만, 지정하지 않은 칸은 관리자만 결재할 수 있습니다.
  - 결재자 이름은 팀원 계정의 이름과 똑같아야 합니다.

■ 꼭 알아두세요
  - 삭제한 자료는 되돌릴 수 없습니다.
  - 사진 파일은 추측하기 어려운 주소로 저장되지만, 사진 주소를 직접 받은 사람은 로그인 없이도 볼 수 있습니다.
